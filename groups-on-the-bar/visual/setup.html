Instalação guiada

Quatro passos

  1. 1

    Baixe o pacote visual

    Ele já está incluído nesta extensão e não acessa nenhum servidor.

    Aguardando detecção do sistema

    Download iniciado. Abra o ZIP na pasta Downloads.

  2. 2

    Extraia o ZIP

    Mantenha os arquivos extraídos juntos. O instalador usa a folha de estilo incluída na mesma pasta.

  3. 3

    Encerre completamente o Firefox

    O assistente mostrará a instrução correta para seu sistema.

  4. 4

    Execute o instalador e reinicie

    A instrução será adaptada ao seu sistema operacional.

Como remover o visual

O pacote inclui um removedor que preserva outras personalizações do Firefox.

Se o chip não aparecer
  • Confirme que o Firefox foi encerrado completamente antes da instalação.
  • Depois de instalar o visual, encerre completamente e abra novamente o Firefox.
  • Confira as instruções do README incluído no pacote.
Baixar para outro sistema

Os três pacotes ficam incorporados nesta extensão. Escolha manualmente se estiver preparando a instalação para outro computador.

macOS Windows Linux

O assistente funciona localmente. Ele não envia seus grupos, favoritos ou histórico para nenhum servidor.
